# Independent reviews

Reviews are separate from implementation reports so the reviewer can independently reconstruct the architecture and challenge both the plan and implementation.

Use `../templates/independent-review.md`.

Recommended naming:

```text
phase-0-independent-review.md
phase-1-independent-review.md
phase-2-independent-review.md
phase-3-independent-review.md
```

Do not turn a review document into a hidden backlog. Once findings are fixed and verified, preserve the review as evidence and reflect current truth in `docs/current-state.md`.
