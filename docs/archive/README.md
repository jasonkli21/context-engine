# Archive

This directory contains superseded or historical project context.

Archived documents are **not authoritative by default** and should not be loaded into ordinary implementation sessions. Keep them only when they provide useful history, rationale, or audit evidence.

When archiving a once-authoritative document:

- mark the replacement/superseding document where practical;
- avoid leaving active links that imply the archived file is current;
- do not use the archive as an accumulating scratchpad.
